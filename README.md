AURA Cafetería Premium 

AURA es un sitio web desarrollado para una cafetería premium, pensado para transmitir una experiencia elegante, moderna y sofisticada. El proyecto cuenta con una página de inicio, carta de productos, reserva de mesas, ubicación con mapa y sección de contacto, buscando que el usuario pueda conocer la cafetería y sus servicios de forma clara e intuitiva.

El sitio fue desarrollado con **HTML5, SCSS/Sass, CSS, Bootstrap y JavaScript**, utilizando **Flexbox, Grid y diseño responsive** para adaptarse a distintos dispositivos. La identidad visual combina tonos oscuros, dorados y crema, acompañados de tipografías e imágenes que refuerzan la estética de AURA y su concepto de **“vivir la experiencia”**.

Enlace a netfily: https://cafeteria-aura.netlify.app/
